مِرقاة - ملفات CSS المحسّنة

الملفات:
- style.css: الأساس، الشريط الجانبي، لوحة التحكم، المواد، الوضع الداكن والتجاوب.
- extra.css: عناصر لوحة التحكم والمهام والمؤقت.
- pages.css: الجدول والتقويم والاختبارات والإحصائيات والملاحظات والإنجازات والمكتبة.

طريقة الربط المقترحة داخل head:
<link rel="stylesheet" href="css/style.css">
<link rel="stylesheet" href="css/extra.css">
<link rel="stylesheet" href="css/pages.css">

ملاحظات:
- حافظت على أسماء الأصناف (classes) المستخدمة في الملفات التي أرسلتها حتى لا تتغير محددات JavaScript.
- احتفظ بترتيب تحميل CSS أعلاه؛ style.css أولاً ثم extra.css ثم pages.css.
- التصميم يجمع بين واجهة حديثة ومسحة كلاسيكية هادئة: أخضر مريمي، عاجي دافئ، ولمسات ذهبي معتّق.
- هذا تحديث CSS فقط؛ اختبار عمل الأزرار وظيفياً يحتاج ملفات HTML وتشغيل المشروع.
