# مِرقاة – ملفات JavaScript بعد الإصلاح

هذه الحزمة تحتوي على ملفات JavaScript التي أرسلتها بعد مراجعة وإصلاح مجموعة من المشكلات، مع الإبقاء على أسماء الملفات قدر الإمكان. تم توحيد اسم `app(2).js` إلى `app.js`.

## أهم الإصلاحات

- توحيد الوصول إلى حقول النماذج باستخدام `form.elements.namedItem` لتفادي تعارض أسماء الحقول مثل `title` مع خصائص عنصر النموذج.
- إصلاح إضافة الأحداث في التقويم بالطريقة نفسها.
- تقوية التخزين المحلي عند وجود بيانات قديمة أو تالفة، والتعامل مع أخطاء القراءة والحفظ.
- جعل عناصر الإحصائيات وأزرار الإشعارات وملف المستخدم أكثر أماناً عند عدم وجود العنصر في الصفحة.
- إزالة مستمعات المظهر المكررة، والإبقاء على مستمع واحد لتبديل الوضع الداكن مع تحديث الرسوم البيانية.
- تحسين التعامل مع بيانات المراجعات القديمة التي قد لا تحتوي على سجل `history`.
- إصلاح تحرير Wake Lock عند انتهاء المؤقت، وإعادة طلبه عند الرجوع إلى التبويب إذا كانت الجلسة مستمرة.
- تحسين التحقق من التواريخ غير الصحيحة.
- الإبقاء على تأكيدات الحذف، وإعادة رسم الصفحة بعد الحفظ الناجح.

## ترتيب تحميل الملفات

مهم: حمّل الملفات كـ JavaScript عادي (Classic Scripts)، وليس `type="module"`، وبالترتيب التالي قبل إغلاق `</body>`:

```html
<script src="js/storage.js"></script>
<script src="js/app.js"></script>
<script src="js/dashboard.js"></script>
<script src="js/common.js"></script>
<script src="js/schedule.js"></script>
<script src="js/tasks.js"></script>
<script src="js/calendar.js"></script>
<script src="js/exams.js"></script>
<script src="js/notes.js"></script>
<script src="js/revisions.js"></script>
<script src="js/statistics.js"></script>
<script src="js/achievements.js"></script>
<script src="js/library.js"></script>
<script src="js/notifications.js"></script>
<script src="js/timer.js"></script>
```

إذا كانت ملفاتك ليست داخل مجلد `js`، عدّل المسارات فقط مع الحفاظ على الترتيب.

## طريقة الاستبدال

1. احتفظ بنسخة احتياطية من مجلد المشروع الحالي.
2. فك ضغط الحزمة.
3. استبدل ملفات JavaScript القديمة بالملفات الموجودة داخل مجلد `js` في الحزمة.
4. تأكد أن ملف `app.js` هو المستخدم في HTML بدلاً من `app(2).js`.
5. افتح الموقع وجرّب الإضافة والتعديل والحذف وإكمال المهام والمراجعات والمؤقت.

## ملاحظة مهمة

الملفات المرسلة كانت ملفات JavaScript فقط؛ لم يصل ملف HTML أو CSS. لذلك تم فحص وإصلاح منطق JavaScript، لكن لا يمكن ضمان توافق كل زر مع عناصر HTML الفعلية أو تنسيقات CSS دون مراجعة ملفات الواجهة أيضاً. لم يتم حذف بيانات `localStorage` أو تغيير مفتاح التخزين `mirqah-data`.
